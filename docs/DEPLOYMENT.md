# Deployment guide — Agent CV on Render (via GitHub)

This guide gets the agent running in the cloud with a public URL, so we can point the
Twilio webhook at it and make the first real phone-call test (Phase 7).

> **Secret flow summary:** the code goes to GitHub WITHOUT keys (the `.env` is in
> `.gitignore`). The keys are entered IN the Render dashboard, which stores them
> encrypted and injects them as environment variables. The same code works locally
> (reads `.env`) and in the cloud (uses the injected variables).

---

## Prerequisites

- A **GitHub** account (free).
- A **Render** account (https://render.com).
- The keys you already use locally: `OPENAI_API_KEY`, `TWILIO_ACCOUNT_SID`,
  `TWILIO_AUTH_TOKEN`, `EMAIL_API_KEY`, `EMAIL_FROM`, `EMAIL_TO`, `MY_PERSONAL_NUMBER`.
- The Twilio **phone number** (the Luxembourg one, once approved).

---

## Step 1 — Push the code to GitHub

1. Create a **new, empty** repository on GitHub (private recommended), with no README.
2. In the project folder, connect the remote and push the `main` branch:
   ```bash
   git remote add origin https://github.com/<your-user>/agent-cv.git
   git push -u origin main
   ```
3. Check on GitHub that the `.env` file does **NOT** appear (it must be absent: protected
   by `.gitignore`). You should see `src/`, `render.yaml`, `package.json`, etc.

---

## Step 2 — Create the service on Render (Blueprint)

The repo includes `render.yaml`, so Render configures the service almost by itself.

1. In Render: **New +** → **Blueprint**.
2. Connect your GitHub account and select the `agent-cv` repository.
3. Render reads `render.yaml` and shows the `agent-cv` service (Node, `starter` plan,
   Frankfurt region, `/health` health check). Accept to create it.

> The `starter` plan (~$7/month) keeps the instance **always awake**. It is required: the
> `free` plan sleeps after 15 min and an incoming call would fail due to the cold start
> (~1 min).

---

## Step 3 — Fill in the secret variables

In the Blueprint, the variables marked "sync: false" are left **empty on purpose**. Go to
your service → **Environment** and fill in:

| Variable | Value |
|---|---|
| `OPENAI_API_KEY` | your OpenAI key |
| `TWILIO_ACCOUNT_SID` | your Twilio SID |
| `TWILIO_AUTH_TOKEN` | your Twilio Auth Token |
| `TWILIO_PHONE_NUMBER` | your Twilio number (the +352 one once approved) |
| `MY_PERSONAL_NUMBER` | your mobile (+34…) for transfers |
| `EMAIL_API_KEY` | your Resend key |
| `EMAIL_FROM` | `onboarding@resend.dev` (or your verified domain) |
| `EMAIL_TO` | your email to receive the summaries |

These come set automatically (do not touch): `HOST=0.0.0.0`, `LOG_FORMAT=json`,
`VALIDATE_TWILIO_SIGNATURE=true`, the OpenAI models, `EMAIL_PROVIDER=resend` and
`STREAM_TOKEN_SECRET` (generated by Render). **`PUBLIC_URL` is not needed**: the code uses
`RENDER_EXTERNAL_URL` automatically.

Save the changes (Render redeploys on save).

---

## Step 4 — Deploy and get the URL

- Render builds (`npm ci`) and starts (`npm start`) the service.
- When the status is **Live**, copy the public URL: `https://agent-cv-XXXX.onrender.com`.
- Check health in the browser: `https://agent-cv-XXXX.onrender.com/health` must respond
  `{"status":"ok","service":"agent-cv"}`.

---

## Step 5 — Point the Twilio webhook

1. In the Twilio console: **Phone Numbers → Manage → Active numbers** → your number.
2. Under **Voice Configuration** → "A call comes in":
   - Type: **Webhook**
   - URL: `https://agent-cv-XXXX.onrender.com/incoming-call`
   - Method: **HTTP POST**
3. Save.

> Signature validation (`VALIDATE_TWILIO_SIGNATURE=true`) requires the webhook URL to
> match the public URL exactly. Since the code uses `RENDER_EXTERNAL_URL`, it should
> match. If calls return `403`, check that the webhook URL is the same
> `https://…onrender.com` (no trailing slash or differences).

---

## Step 6 — Real end-to-end test

1. Call the Twilio number.
2. The agent should greet you in English and adapt to your language.
3. Try: ask about the profile, request a **transfer** (your mobile rings), and **leave
   your contact details**.
4. Hang up and check your email: the call **summary** should arrive.

---

## Operation and maintenance

- **Update**: `git push` to `main` → Render redeploys automatically.
- **Logs**: the service's **Logs** tab (in JSON, via `LOG_FORMAT=json`).
- **Active guardrails** (Phase 6): Twilio signature, WebSocket token, concurrency/daily
  limit (`MAX_CONCURRENT_CALLS`, `MAX_CALLS_PER_DAY`), silence timeout, max caller turns,
  OpenAI reconnection. They can be tuned by adding those variables under **Environment**
  (see `.env.example`).
- **Cost**: `starter` instance (~$7/month) + OpenAI usage (per call minute), Twilio
  (number + minutes) and Resend (free at the expected volume).
